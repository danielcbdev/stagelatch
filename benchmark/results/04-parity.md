# Task 4: parity

Recorded on 2026-11-18. Apple M4, macOS 27.2.1.

## The oracle

`runOracle` exports the index with `git write-tree` and
`git archive | tar -x` to a temporary directory under `.benchmark/tmp`,
copies the package's `.dart_tool/package_config.json`, runs the SDK's
`dart analyze --format=json --cache=<own dir>` on the exported package and
`dart format --output=json` on each requested file, maps the paths back
and deletes the directory in a `finally`.

`diffResults` compares diagnostics as the set of
`(path, code, severity, offset, length)` of the requested files, and the
formatted text byte for byte.

## Older SDK: Flutter 3.44.9, Dart 3.12.2

The previous stable minor of Flutter is 3.44 (latest patch 3.44.9,
installed with FVM 4.3.2). The corpus cannot be re-resolved on it: its
lockfile needs Flutter >=3.47, and without the lockfile `qr >=4.0.1` needs
Dart ^3.13 (`flutter pub get --dry-run` on an export of the pinned
pubspec). The plan's fallback applies: a fixture, `old_sdk`, generated by
`benchmark/bin/setup_fixture.dart` with `sdk: ^3.12.0`, Flutter as a
dependency, `flutter_lints` 6.0.0 in an `include:`, two extra lints and
`formatter: page_width: 100`. Its scenarios mirror s3 and s10 (one
error, one warning, one lint, one unformatted file, the same unstaged
trap; s10 touches a file imported by 110 others).

## Summary

| embedded | 2 differences | 3 differences | 2 differences | 2 differences |

Every difference of the embedded probe is a missing lint
(`directives_ordering`, `prefer_const_constructors`): `package:analyzer`
on pub.dev does not ship lint rule implementations. Errors, warnings and
formatting matched on both SDKs, `page_width` 120 and 100 included.

Not visible in these diffs, but seen in Task 2: for the unstaged trap
(analyzed without overlays) the embedded analyzer 14.7.0 reports
`undefined_instance_member_read` where the SDK reports `undefined_method`.
A snapshot containing that error would be a parity difference too.
